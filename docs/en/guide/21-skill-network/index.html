21. Skill co-occurrence network [bonus]

3 min read · 4 tables · 2 figures · 3 code cells

If two skills are requested together in a job posting many times, they probably form a “work bundle”. We build a network whose nodes are skills and whose edges are the co-occurrence of two skills in a posting: node size by skill frequency and edge thickness by the number of co-occurrences. We then measure skill communities and the change in centrality over two years.

from itertools import combinations
from collections import Counter

TOP_NETWORK = 35
network_skills = skills_long.skill.value_counts().head(TOP_NETWORK).index
skill_ads = skills_long.loc[skills_long.skill.isin(network_skills), ['ad_id', 'skill']].drop_duplicates()
pair_counter = Counter()
for _, group in skill_ads.groupby('ad_id').skill:
    names = sorted(set(group))
    if 1 < len(names) <= 12:
        pair_counter.update(combinations(names, 2))

frequency = skill_ads.skill.value_counts()
graph = nx.Graph()
for skill, count in frequency.items():
    graph.add_node(skill, frequency=int(count))
for (first, second), weight in pair_counter.items():
    if weight >= 20:
        graph.add_edge(first, second, weight=int(weight))
graph.remove_nodes_from(list(nx.isolates(graph)))

communities = list(nx.community.greedy_modularity_communities(graph, weight='weight'))
community_of = {node: index for index, members in enumerate(communities) for node in members}
betweenness = nx.betweenness_centrality(graph, weight='weight')
weighted_degree = dict(graph.degree(weight='weight'))

network_summary = pd.DataFrame({'مقدار': [f'{graph.number_of_nodes():,}', f'{graph.number_of_edges():,}',
                                          f'{len(communities)}', f'{len(skill_ads):,}',
                                          f'{sum(pair_counter.values()):,}']},
                               index=['گره (مهارت)', 'یال (هم‌رخدادی)', 'جامعه مهارتی',
                                      'ردیف مهارت-آگهی', 'کل جفت هم‌رخداد'])
show_table('21.1', 'خلاصه شبکه مهارت‌ها', network_summary, sample='کل دوره', period=False,
           index_name='شاخص')

Interpretation of table 21.1 and figure 21.1: The network was built from 35 frequent skills and 290 edges with at least 20 co-occurrences remained. Node sizes are proportional to skill frequency and edge thicknesses are proportional to the number of co-occurrences. The size of the network (not the number of nodes but the density of edges) shows that Iran's skill basket is “concentrated”: a limited number of skills repeat together many times.

Interpretation of table 21.2: Four skill communities were identified:

  1. Office and Iranian financial/administrative software (12 skills): Excel, Word, PowerPoint, Outlook, Access along with Sepidar, Rahkaran and Hamkaran System. This community is the core of the administrative market.
  2. Development and infrastructure (11 skills): SQL Server, HTML/CSS, Git, JavaScript, Network+, C#.
  3. Design and digital content (9 skills): Photoshop, Illustrator, WordPress, Premiere, After Effects, Google Analytics.
  4. Engineering and industrial design (3 skills): AutoCAD, SolidWorks, CATIA.

Important note: Iranian domestic accounting software were placed in the same office community, not in the development community; that is, from the market's point of view these skills are “administrative tools” rather than “technology”. This is an important difference from global markets.

def annual_degree(year):
    frame = skill_ads.merge(ads.loc[ads.jyear.eq(year), ['ad_id']], on='ad_id')
    counter = Counter()
    for _, group in frame.groupby('ad_id').skill:
        names = sorted(set(group))
        if 1 < len(names) <= 12:
            counter.update(combinations(names, 2))
    degree = {skill: 0 for skill in network_skills}
    for (first, second), weight in counter.items():
        degree[first] += weight
        degree[second] += weight
    return pd.Series(degree).sort_values(ascending=False), counter

Key figures: skill network

  • Skills in the network: 35

Interpretation of tables 21.3 and 21.4 and figures 21.2 and 21.3: The most central nodes of the network are the office skills: Excel with a weighted degree of 268,505 and Word with 253,683. But betweenness centrality — the ability to connect communities — tells another story: WordPress (0.23), Visio (0.16), Outlook (0.14) and Illustrator (0.11) have the highest betweenness centrality; that is, these skills are bridges between the administrative, design and technology communities.

In the two-year comparison the ranks have remained almost constant (the largest rank change is only 2 places), but the degree of every skill has grown; part of this growth is the growth of the whole job posting market. The largest relative growth in degree: Google Analytics (+241%), Adobe Premiere (+69%), Sepidar (+66%), WordPress (+63%) and AutoCAD (+60%).

Message for the job seeker: If you want to move between fields, the “bridge” skills (WordPress, Visio, advanced Excel) have high connective value; if you want to go deep in one field, strengthen the central skills of that same community.
