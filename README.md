## ۱. در یک نگاه

این پروژه، داده‌های خام آگهی‌های استخدامی پلتفرم **جاب‌ویژن** را به مجموعه‌ای از شاخص‌ها، الگوها و پیشنهادهای عملیاتی برای سه گروه مخاطب تبدیل می‌کند:

- **مدیران منابع انسانی و صاحبان کسب‌وکار:** بسته جبران خدمات رقابتی، زمان‌بندی انتشار آگهی، مهارت‌های دارای ارزش افزوده و راه تمایز آگهی از رقبا.
- **کارجویان:** نقشه مهارت‌های پرتقاضا، بازده تحصیلات و سابقه، شکاف‌های جغرافیایی و جنسیتی دستمزد.
- **تحلیلگران و سیاست‌گذاران بازار کار:** تصویری کمّی از تحول ساختار تقاضا، فصلی‌بودن و تمرکز منطقه‌ای در بازه ۱۴۰۱ تا ۱۴۰۲.

خروجی نهایی صرفاً مجموعه‌ای از نمودار نیست؛ هر بخش به یک پرسش قابل تصمیم‌گیری پاسخ می‌دهد، مبنای محاسبه و محدودیت آن را روشن می‌کند و در پایان به یک بسته پیشنهادی اجرایی می‌رسد.

## ۴. نصب و اجرا

پیش‌نیاز: **Python 3.12 یا جدیدتر**.

```bash
python -m venv .venv

# Linux / macOS
source .venv/bin/activate
# Windows (PowerShell)
.\.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m notebook jobvision_analysis.ipynb
```

سپس در نوت‌بوک، هسته محیط مجازی را انتخاب کنید و همه سلول‌ها را به‌ترتیب با `Restart & Run All` اجرا کنید. نوت‌بوک تکرارپذیر است: در صورت نبود فایل داده، مسیر جایگزین و دستور دانلود را نشان می‌دهد.

### اجرا در Google Colab

نوت‌بوک برای اجرا در Colab نیز آماده است. در سلول بارگذاری داده، مسیر `JobVision-data/` بررسی می‌شود و در صورت نبود فایل، داده مستقیماً از Hugging Face دانلود می‌شود. برای اجرا:

1. نوت‌بوک را در Colab باز کنید.
2. سلول نصب وابستگی‌ها را اجرا کنید.
3. سلول‌ها را از ابتدا به‌ترتیب اجرا کنید.

## ۷. محدودیت‌ها

- داده فقط آگهی‌های **منتشرشده** در جاب‌ویژن را پوشش می‌دهد و نماینده کل بازار کار ایران نیست.
- نام شرکت‌ها ناشناس‌سازی شده است؛ تحلیل کارفرما در سطح ویژگی‌های شرکت انجام می‌شود، نه برند.
- حقوق فقط در حدود یک‌سوم آگهی‌ها اعلام شده است؛ همه تحلیل‌های حقوقی روی همین زیرمجموعه انجام و سوگیری آن جداگانه بررسی می‌شود.
- «بازه سنی» و «جنسیت» ترجیح کارفرما در آگهی است، نه ویژگی واقعی نیروی استخدام‌شده.
- دو ماه ابتدا و انتهای داده ناقص‌اند و در تحلیل روند کنار گذاشته می‌شوند.
